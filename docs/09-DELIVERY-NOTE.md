# Delivery Note

## Project character
This is a small one-off learning/practical project, not a long-term SaaS commitment.

## Commercial separation
The application project and any personal loan/help between family members are separate matters.

The application should be useful on its own. No payment or loan should be represented as payment for the application unless both parties explicitly agree to a separate transaction.

## Handover
Deliver:
- Production URL
- Basic operator access
- Short usage note
- Repository source
- Deployment notes

## Support
No automatic long-term support obligation is implied by the MVP. Future changes can be discussed separately if needed.
