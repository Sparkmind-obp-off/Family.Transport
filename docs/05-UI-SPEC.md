# UI Specification

## Design direction
- Mobile-first
- Fast
- Calm
- Practical
- High information density without clutter
- Large tap targets
- Minimal navigation

## Navigation
- Dashboard
- Trips
- Drivers
- Vehicles

## Dashboard
Show:
- Today
- Upcoming
- Needs attention

Trip card:
- Time
- Route
- Customer
- Passenger count
- Vehicle
- Driver
- Status

Actions:
- Open
- WhatsApp customer
- WhatsApp driver

## Trip detail
Show:
- Trip status
- Date/time
- Route
- Customer
- Contact
- Passenger count
- Vehicle
- Driver
- Price
- Notes

Actions:
- Edit
- Assign
- WhatsApp
- Change status

## Forms
Prefer short forms and sensible defaults. Avoid multi-step forms.
