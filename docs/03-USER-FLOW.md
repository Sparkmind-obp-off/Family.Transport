# User Flow

## Main flow
1. Open dashboard
2. See today's and upcoming trips
3. Create new order
4. Enter customer and trip details
5. Save as Pending
6. Coordinate availability through WhatsApp, then mark Confirmed
7. Assign active driver and vehicle (either can be saved first)
8. Complete assignment automatically marks Assigned; retained resources are revalidated
9. On trip day, mark On Trip
10. After completion, mark Completed

## Exception flow
### No driver available
Keep trip Pending and coordinate externally through WhatsApp.

### No vehicle available
Keep trip Pending and use an external partner. Record partner/source in notes or optional partner field.

### Customer changes schedule
Edit the trip.

### Trip cancelled
Mark Cancelled rather than deleting the order.

## Communication principle
The application records operational truth; WhatsApp remains the communication layer.
