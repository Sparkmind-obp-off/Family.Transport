# Scope — MVP

## P0 — Must have

### Dashboard
- Today's trips
- Upcoming trips
- Status summary
- Quick add order

### Orders / Trips
- Customer name
- Customer WhatsApp
- Trip date
- Trip time
- Pickup
- Destination
- Passenger count
- Vehicle
- Driver
- Price
- Notes
- Status

### Drivers
- Name
- WhatsApp
- Notes
- Active/inactive

### Vehicles
- Vehicle name/type
- Identifier/plate if needed
- Notes
- Active/inactive

### Quick actions
- WhatsApp customer
- WhatsApp driver
- Edit trip
- Change status

## P1 — Only if easy
- Search/filter trips
- Upcoming calendar view
- Partner/source field
- Basic cost notes

## Explicitly out of scope
- Customer login
- Driver login
- Online booking checkout
- Payment gateway
- Real-time GPS tracking
- Automated price calculation
- Accounting ledger
- Payroll
- Partner self-service
- Automated WhatsApp messaging
- AI features

## Scope rule
If a feature does not directly help the operator coordinate a trip, it should not enter MVP.
