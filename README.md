# Family Transport Manager

Mini operational management app for Family Transport.

## Purpose
A lightweight internal tool to help the operator manage transport orders, schedules, vehicles, drivers, and trip status in one place.

## Owner / Operator
Family Transport — operated by Fahruk.

## Core workflow
Customer request → create order → coordinate vehicle/driver → confirm trip → monitor → complete.

## MVP
- Dashboard / today's trips
- Order management
- Driver management
- Vehicle management
- Trip status
- Basic price and notes
- WhatsApp shortcuts

## Non-goals
- Online payment
- Customer accounts
- Driver accounts
- Real-time GPS tracking
- Automated pricing engine
- Partner portal
- Accounting
- Complex CRM
- AI automation

## Suggested stack
Cloudflare-first full-stack deployment.

## Product principle
Build only what can reduce real coordination work. WhatsApp remains the primary communication channel.
